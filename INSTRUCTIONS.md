# Инструкции по использованию сайта Zoobastiks

## 📸 Добавление фотографий в галерею

1. Создайте папку `assets/gallery/` если её нет
2. Загрузите фотографии в эту папку
3. Назовите файлы по шаблону:
   - `gallery-1.jpg`
   - `gallery-2.jpg`
   - `gallery-3.png`
   - и т.д.

4. Фотографии будут автоматически отображаться на странице `/gallery`

**Рекомендации:**
- Используйте формат JPG для фотографий (меньший размер)
- Оптимизируйте изображения перед загрузкой
- Рекомендуемый размер: 1920x1080 или меньше
- Максимальный размер файла: 2MB

## 🔄 Обновление информации о сервере

Отредактируйте файл `data/server-info.json`:

```json
{
  "server": {
    "name": "Zoobastiks",
    "ip": "Zoobastiks.20tps.name",
    "port": 20054,
    ...
  }
}
```

После изменения запустите `deploy.bat` для публикации изменений.

## 🌍 Добавление нового языка

1. Создайте файл `data/locales/{код_языка}.json`
2. Скопируйте структуру из `ru.json`
3. Переведите все строки
4. Добавьте опцию в `index.html`:
```html
<option value="{код_языка}">{Название}</option>
```

## 🎨 Настройка цветов и темы

Отредактируйте CSS переменные в `css/core.css`:

```css
:root {
    --color-primary: #55C555;
    --color-secondary: #FF6B35;
    --color-accent: #FFD23F;
    ...
}
```

## 📱 Добавление новой страницы

1. Создайте файл `js/pages/{название}.js`:
```javascript
import { i18n } from '../i18n.js';

export async function render() {
    return `<div>...</div>`;
}

export async function init() {
    // Инициализация страницы
}
```

2. Добавьте маршрут в `js/router.js`:
```javascript
this.routes = {
    '/': 'home',
    '/{название}': '{название}',
    ...
};
```

3. Добавьте ссылку в навигацию `index.html`

4. Добавьте переводы в `data/locales/*.json`

## 🚀 Деплой на GitHub Pages

### Автоматический деплой

1. Убедитесь, что токен GitHub установлен:
```cmd
set GITHUB_TOKEN=your_token_here
```

2. Запустите:
```cmd
deploy.bat
```

### Ручной деплой

1. Клонируйте репозиторий
2. Внесите изменения
3. Закоммитьте и запушьте:
```bash
git add .
git commit -m "Update website"
git push origin main
```

GitHub Actions автоматически задеплоит сайт на GitHub Pages.

## 🔧 Устранение неполадок

### Сайт не загружается
- Проверьте, что все файлы на месте
- Убедитесь, что GitHub Pages включен в настройках репозитория
- Проверьте консоль браузера на ошибки

### Фотографии не отображаются
- Проверьте путь к файлам
- Убедитесь, что файлы загружены в `assets/gallery/`
- Проверьте формат файлов (JPG, PNG)

### Локализация не работает
- Проверьте, что файлы переводов существуют
- Убедитесь, что JSON файлы валидны
- Проверьте консоль браузера на ошибки загрузки
