# Zoobastiks Minecraft Server Website

Официальный сайт сервера Zoobastiks - масштабная, модульная, ультра-производительная web-платформа.

## 🚀 Особенности

- **Модульная архитектура** - легко расширяемая структура
- **Многоязычность** - поддержка RU, EN, UA с переключением без перезагрузки
- **Производительность** - оптимизация, lazy-loading, виртуализация
- **Адаптивный дизайн** - работает на всех устройствах
- **Minecraft-стиль** - футуристичный UI в стиле Minecraft
- **Интерактивность** - анимации, эффекты, параллакс
- **SEO оптимизация** - мета-теги, структурированные данные

## 🛠️ Установка и запуск

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Z-oobastik-s/Zoobastiks.git
cd Zoobastiks
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

### Деплой на GitHub Pages

1. Убедитесь, что токен GitHub установлен в переменной окружения:
```bash
set GITHUB_TOKEN=your_token_here
```

2. Запустите скрипт деплоя:
```bash
deploy.bat
```

Скрипт автоматически:
- Клонирует/обновляет репозиторий
- Копирует файлы
- Коммитит изменения
- Публикует на GitHub Pages

## 📝 Добавление контента

### Фотографии в галерею

1. Загрузите фотографии в папку `assets/gallery/`
2. Назовите файлы по шаблону: `gallery-{номер}.jpg`
3. Фотографии будут автоматически загружены на странице галереи

### Обновление информации о сервере

Отредактируйте файл `data/server-info.json` с актуальной информацией о сервере.

### Добавление переводов

Добавьте новые ключи в файлы `data/locales/*.json` для поддержки новых языков или обновления существующих переводов.
